LOGO DE LA TIENDA
=================

  logo.png            <- el que usa el sistema (fondo transparente)
  logo-original.jpeg  <- el archivo tal como llego, por si se necesita

SI ALGUN DIA CAMBIA EL LOGO
---------------------------
1. Guarda el archivo nuevo aqui como logo.jpeg (o logo.jpg / logo.png).
2. Corre:  npm run logo
3. Eso le quita el fondo, lo recorta y deja un logo.png listo para usarse.

El paso 2 hace falta cuando el archivo es JPEG, porque ese formato no
puede tener fondo transparente: trae el suyo pintado. Sin quitarselo, el
logo se veria como un recuadro pegado encima del marfil de la barra.

Si el archivo nuevo YA viene en SVG o en PNG con fondo transparente, no
hace falta el paso 2: guardalo como logo.svg o logo.png y listo.

QUE BUSCA EL SISTEMA, EN ESTE ORDEN
  logo.svg  ->  logo.png  ->  logo.webp  ->  logo.jpg  ->  logo.jpeg
